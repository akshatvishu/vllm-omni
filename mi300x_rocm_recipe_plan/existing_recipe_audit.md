# Existing recipe audit and MI300X capacity check

The capacity check answers only whether 192 GB of HBM3 is enough based on checked checkpoint sizes, recipe measurements, or a smaller validated GPU. A pass does not mean that every kernel works on ROCm.

## Recommended scope

Add ROCm sections to the six existing recipes after successful runs. Add a new `recipes/k2-fsa/OmniVoice.md` recipe after the OmniVoice run passes. Keep full Ming Flash Omni 2.0 out of the single MI300X recipe. A standalone TTS subsection can be added only if the optional Ming Flash TTS run passes.
